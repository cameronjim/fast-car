# evaluation

The pre-registered evaluation protocol and its results. `prereg` holds pre-registration
documents, committed before any data is collected for that evaluation; `protocol` holds the
session runner that handles condition interleaving, run order, and checklists; `analysis`
holds the notebooks and scripts that produce the reported numbers, and nothing under it may
be edited after a pre-registered result is reported except as an additive, clearly-labeled
post-hoc section. See `claude-docs/02-repo-layout.md` and `claude-docs/09-evaluation.md`.
