# prereg

`pnp-v0.2-split.yaml` is the frozen train and held-out split of the real bags for Plug-and-Play v0.2.
`docs/notes/preregistration-pnp-v0.2.md` is the pre-registration: the gates, thresholds and counting rules.
Both are frozen. A correction is a dated appendix by the owner, never an edit; the split SHA-256 is
`bc5185c912ece67a6177581f1b37adaaa9101b34ee1efe9881af7723681aef83`.
The analysis code that implements them is `evaluation/analysis` (package `racer_eval`).
